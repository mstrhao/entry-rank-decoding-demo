# Joint-soft single-trial decoding

输入`epochs[N,P,T]`和完整整数`target_labels[N,R]`（位置1..K），在训练集内通过controlled TG与全目标GLM联合学习一个共享Entry及R个Rank功能子空间，再训练固定multinomial读出器。输出`probabilities[R+1,K,N,T]`；预测不接收测试标签。

当前唯一模拟展示：[有序ring命名入口与全部结果](ordered-ring/README.md)。位置按一阶谐波生成、rho=0，真实rank2；学习与解码保留完整K−1 GLM和数值rank5basis，绝不截2维。本教程仅使用合成数据。

## 换成自己的数组

```python
from jointdecode import Config, run_oof_decoding
config = Config()  # 仅在时间设计完全一致且输入已处理时直接使用
result = run_oof_decoding(epochs, target_labels, config,
                          trial_ids=trial_ids, groups=groups,
                          outer_fold=fold_ids)
# result['probabilities'].shape == (R+1, K, N, T)
```

Config默认`as_is`，不会重复减基线/平滑。raw输入可明确选择`baseline_subtract_unsmoothed`或`baseline_subtract_smooth7`。默认时间轴[0,6)s，30Hz；onset1/2.3/3.6s，baseline[.3,.8)，Entry各onset+[.2,.6)，Rank均[4.5,5.5)。所有窗口左闭右开，必须由使用者确认，不能由数值或标签猜测。

共享原始帧或同源片段必须同group，同group不能跨折。标签不得缺失、为0或NaN；全目标GLM不可识别时明确报错，ridge不修补不可识别。若输入已重排须提供原trial_order，不能由ID猜测。

```bash
jointdecode --epochs epoch.npy --labels target_labels.npy --config config.json \
  --folds fold_ids.npy --groups groups.npy --trial-ids trial_ids.npy --output runs/my-data
```

输出包括完整逐位置概率/logits、OOF原trial轴、逐折GLM/scaler/TG hits-counts/先验/增益/模板/basis/读出权重、inner/outer ID/group审计、软件/源码hash及收敛记录。ground truth仅事后评估；预测不乘时间增益、不做利用测试标签的nuisance残差化。

## 解释边界

TG在外训练集内部另设内折，内验证其他目标标签仅用于controlled TG条件化。空间不是独立PCA，坐标通过拼接basis的同时ridge估计；读出是冻结K类softmax。基线 logistic 的 softmax 输出不自带校准保证；Gaussian 与训练内温度扩展另行评估。空间也不是唯一可加信息分解。

二维PCA只用于展示，主夹角/VAF用完整操作性空间。五折不是独立重复；7帧居中平滑含未来约.1s；无重复标签设计可产生排除位置信息。训练模板几何不是held-out神经轨迹。详见[数学约定](docs/METHODS.md)、[仓库导览](../README.md)和[共同表示的重构诊断](model-comparison/README.md)。
